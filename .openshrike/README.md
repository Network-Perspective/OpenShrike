# OpenShrike Init

This directory is generated by `shrike init`.

- `checks/` stores the project-local Markdown checks that Shrike executes.
- `project.json` stores repo-local Shrike defaults such as the selected policies and scan settings.
- `opencode.json` is a Shrike-owned OpenCode overlay with separate scan and fix agents.
- `.gitignore` keeps generated `artifacts/` files out of version control.
- User-global OpenCode config and credentials remain outside this repository.

Re-run `shrike init` to seed additional checks from different policies or choose different saved defaults.
After initialization, `shrike scan` reads Markdown checks from `checks/` and uses these saved defaults automatically.
